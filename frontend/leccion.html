1. Cómo usar el Ratón (Mouse) y el Teclado

El ratón y el teclado son las herramientas principales que te permitirán darle instrucciones a tu computadora.

Los botones del Ratón (Mouse)

Clic Izquierdo (Principal)

Se usa con el dedo índice. Sirve para seleccionar cosas, abrir carpetas y pulsar botones en la pantalla.

Clic Derecho (Opciones)

Se usa con el dedo medio. Sirve para abrir una pequeña lista de opciones o menús adicionales.

Teclas más importantes

  • Tecla ENTER (Entrar): Confirma una acción o pasa al siguiente renglón al escribir.
  • Barra Espaciadora: La tecla larga ubicada abajo; sirve para dejar un espacio entre palabras.
  • Tecla Borrar (Retroceso): Te permite borrar la última letra o palabra escrita.

¡Consejo Útil!

No te apresures. Tómate el tiempo necesario para mover el ratón con suavidad sobre la mesa.
